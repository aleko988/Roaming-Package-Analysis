# GLOBALCELL Roaming Package Performance Analysis

## Overview
Analysis of 9 months of real telecom roaming package sales data (Jul 2025 – Mar 2026) 
from GLOBALCELL, a Georgian telecom company. Built using Excel for data preparation 
and Power BI for interactive dashboard visualization.

## Business Questions Answered
- Is roaming revenue growing or declining over time?
- Which countries generate the most revenue?
- Which package sizes do customers prefer?
- Which destinations are most expensive per GB?

## Key Findings
- Revenue grew 145% from 7.7K to 18.9K GEL over 9 months
- Europe+, Italy, Turkey account for top 3 revenue destinations
- 1GB packages sell most by volume but 10GB packages generate most revenue
- Tajikistan (52 GEL/GB) and Monaco (47 GEL/GB) are most expensive destinations

## Tools Used
- Excel — data cleaning, preparation, calculated columns
- Power BI — interactive dashboard, DAX measures, slicers
